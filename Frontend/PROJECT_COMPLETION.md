## 🔄 State Flow

```
User Login
    ↓
Set currentUser in Redux (auth.currentUser)
    ↓
Render based on currentUser.role
    ↓
Navigate between pages (update currentPage)
    ↓
Pages fetch data from Redux slices
    ↓
Dispatch actions to update state
    ↓
Components re-render with new state
```
